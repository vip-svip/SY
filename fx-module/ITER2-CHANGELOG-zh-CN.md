# FX 1.0.0 — Iter2 迭代记录

本次迭代保持模块版本 `1.0.0` / `versionCode=10000`，不覆盖此前交付的 ZIP。

## 修复

- VPN 模式切换不再仅凭 `vpn_node` 配置字段是否非空来判断节点已就绪。
- 将保存的节点标识与当前启用节点列表比对；节点已删除、停用或订阅刷新后留下过期标识时，允许用户保存直连/全局/规则模式偏好。
- 没有可用已选节点时，全局/规则模式只保存模式并显示等待节点状态，不调用会因缺少代理监听而失败的流量接管流程。
- 配置保存失败时恢复切换前的模式，而不是无条件强制恢复为直连。
- 扩展无节点模式回归测试，覆盖残留的过期节点标识。

## 验证范围

已运行：模式切换无节点回归、直连无节点回归、订阅缓存回归、JS 订阅生命周期回归、订阅导入持久化事务回归、订阅 URL scheme 回归、scripts 下 Shell 语法检查、页面内联 JavaScript 语法检查。

以上为当前工作环境的主机侧测试，不代表 OnePlus 12 真机验收。指定订阅 URL 的远程响应仍未能在当前环境完成验证，因此本迭代不宣称该 URL 已成功下载或解析。
