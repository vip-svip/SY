# FX 1.0.0 — 重命名与本轮验证

- KernelSU 管理器显示名称改为 `FX`。
- ZIP 文件名改为 `FX-v1.0.0.zip`。
- 公开版本号固定为 `1.0.0`。
- **保留内部模块 ID `privacyguard`**，避免 KernelSU 将其识别为全新模块，导致与已安装旧版并存或升级路径断裂。
- `webroot/index.html` 未修改；证书子模块目录未改名。

## 验证边界

本次重命名不代表系统 Hosts 文本编辑器或订阅独立拦截引擎已经完成。当前 `scripts/apply.sh` 仍将订阅解析后合并到生成的 Hosts 输出；若直接移除合并逻辑，会让订阅规则失效，因此没有做破坏性拆除。下一步需要先实现并接通独立的订阅执行引擎，再迁移数据路径与界面。
