# FX built-in optional **开屏广告** domain set (independent category).
#
# Purpose: block the network side of cold-start / splash advertising. A splash ad is
# fetched at launch from a dedicated ad server before the first frame; blocking that
# endpoint means the app has no creative to draw and falls through to its own
# first-screen content. In-app LSPosed hooks cover the SDK calls; this list covers the
# fetch by apps FX cannot hook and by SDKs that resolve creatives themselves.
#
# Format: hosts. Disabled by default. Independent of the ad/tracker list.
#
# Scope rules used when building this list:
#   * only splash / launch-ad creative and configuration endpoints
#   * never a bare registrable domain that also serves user-facing traffic
#   * never an app's own API host, so the app still loads its real first screen
#   * no wildcard-only entries; every line is a concrete host
