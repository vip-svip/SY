网络防泄露

DNS · IPv6 · 真实 IP · VPN 断连 · 代理节点 · 系统加固 六维
代理内核（加密隧道）内置，随包分发
这一项和上面六项的关系：DNS/IP/节点收敛是「别泄露」，而代理是真加密。 只有内核跑起来、节点通，运营商在网络侧才看不到你访问了哪些站点 —— 否则「运营商挡不住」就只是句空话。
内核已随包内置（sing-box，arm64/armv7/amd64 三种架构），不需要联网下载。
内核-
架构 / 版本-
运行状态-
配置 / 节点-
一键操作不确定开哪个就点这个
下面六项各自防一类泄露。点「全部开启」会一起打开并立即生效；每一项也能单独开关，下方有各自的说明与状态。
总状态-
① 防 DNS 明文泄露53 / 853 端口收敛
未加密的 DNS 查询会被中间网络看到你访问了哪些域名。开启后拦截明文 DNS（53）与加密 DNS（853）直连，把解析收敛到本模块。
状态-
② 防 IPv6 旁路无 v6 出口时整链阻断
很多规则只拦 IPv4，流量走 IPv6 就绕过去了。没有可用 IPv6 出口时开启本项，直接阻断 v6 出站（含 sysctl 兜底）。关闭时会**还原** sysctl，不会把 IPv6 永久关掉。
状态-
③ 防真实 IP 泄露STUN / WebRTC 探测面收敛
网页可用 WebRTC/STUN 探到你的真实出口 IP，绕过代理。开启后收敛这些探测面（3478/19302 等端口与组播）。
状态-
④ 防 VPN 断连裸奔kill-switch
VPN/代理一断，流量会以真实 IP 直连。开启后由守护进程盯着，一旦代理不可用就阻断普通直连，避免"断线瞬间"泄露。
状态-
⑤ 防代理节点泄露代理不可用时不直连
代理节点配置错误或挂掉时，应用可能自动回退直连。开启后代理不可用即阻断，宁可断网也不泄露。
状态-
⑥ 系统隐私加固sysctl 收敛
收紧内核网络参数：反向路径过滤、拒绝 ICMP 重定向、拒绝路由通告、IPv6 临时地址。关闭时会**逐项还原**到默认值。
状态-
运营商隐私收敛明文 DNS + v6 + STUN + 加固
一次把上面①~③⑥ 组合起来，专门降低运营商侧可观测面。

FX 深度抵抗

上报端点拦截 · 安装清单读取面收敛（96110 / 运营商 / 网站）
它做什么、不做什么如实说明
能做：阻断设备上那些"把上网记录 / 安装应用清单交出去"的上报端点；
收紧目标应用读取安装清单与使用记录的权限面。

做不到（不假装）：运营商在网络侧看你流量 —— 那需要加密隧道；
"屏蔽 96110 来电" —— 会影响紧急联络，且各 ROM 实现不可靠，本模块不做；
"证明谁读了剪贴板/安装清单" —— 系统没有这个公开接口。
